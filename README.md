# EmployeePortal.API

Employee management API built with C# and ASP.NET Core. Manage employees, departments, and leave / records via REST endpoints.

## Tech Stack
C#, ASP.NET Core Web API (.NET 8), Entity Framework Core, SQL Server, Swagger

## Features
- Employee CRUD
- Department management
- API controllers + Services layer
- Swagger / OpenAPI docs

## How to Run
1. Clone repo
2. Open EmployeePortal.API.sln in Visual Studio
3. Update connection string in appsettings.json
4. Run: Update-Database
5. Run project - Swagger will open

## What I Learned
Built a clean API with Controller / Service separation, EF Core, and .NET 8.
